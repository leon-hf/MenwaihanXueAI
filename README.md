# 门外汉学 AI，不用怕！

> 最通俗的讲AI，最硬核的算法，文科生都能听懂的 AI！

## 这是什么？

这是一本写给**完全零基础**读者的 AI 入门书。

不讲虚的，不堆术语。从"什么是人工智能"一路讲到 Transformer、大语言模型、多模态、强化学习。每一篇都用大白话 + 图解 + 代码示例，让你真正搞懂 AI 到底在干什么。

全书 **58 篇文章**，**286 张图解**，覆盖从基础概念到前沿技术的完整知识体系。

## 内容概览

全书按学习顺序分为 **5 大部分 19 章**：

### 第一部分 人工智能基础（第1-2章）
搞懂 AI、模型、参数、训练这些最基本的概念，建立对机器学习"万物皆可向量"的直觉。

### 第二部分 深度学习与经典算法（第3-5章）
从神经网络的训练原理（前向传播、反向传播、梯度下降），到逻辑回归、决策树、SVM 等经典算法，再到卷积神经网络（CNN）看懂图像识别。

### 第三部分 自然语言处理（第6-11章）
这是全书重头戏。从词向量开始，一路走过 RNN、Seq2Seq、注意力机制，然后**六讲吃透 Transformer**（GPT 的核心架构），再到 DeepSeek 的架构创新和大模型评估方法。

### 第四部分 多模态大模型（第12-14章）
AI 怎么同时理解图片和文字？CLIP、Flamingo、BLIP-2、LLaVA、Stable Diffusion，看懂多模态的前世今生。

### 第五部分 强化学习（第15-19章）
从马尔科夫决策过程和贝尔曼方程出发，到 Q-Learning、深度 Q 网络、策略梯度、PPO，最后讲到偏好对齐（DPO/GRPO）--这就是 ChatGPT 最后一步训练用的技术。
