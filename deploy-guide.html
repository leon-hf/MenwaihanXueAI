出书部署指南

两种发布方式：GitHub Pages 在线阅读 + Markdown 离线文件

方案一：GitHub Pages 在线阅读

将全部 HTML 文件部署到 GitHub Pages，读者通过浏览器在线阅读，支持精美排版、公式渲染、代码高亮。

步骤 1：创建 GitHub 仓库

  1. 登录 GitHub，点击 New repository
  2. 仓库名填 ai-book（或任意名称）
  3. 选择 Public（公开，否则 Pages 需要付费）
  4. 不要勾选 "Add a README file"（我们已经有了）
  5. 点击 Create repository

步骤 2：推送代码

在终端执行以下命令（替换 你的用户名）：

# 进入项目目录
cd ~/study/门外汉学AI\(第三稿\)

# 初始化 Git
git init
git add .
git commit -m "门外汉学AI 全58篇"

# 推送到 GitHub
git branch -M main
git remote add origin https://github.com/你的用户名/ai-book.git
git push -u origin main
提示
如果文件较多推送较慢，可以先只推 HTML 和 images：
git add index.html sample_*.html .nojekyll _config.yml README.md .gitignore images/
再推 MD 文件：git add *.md && git commit -m "添加MD源文件" && git push

步骤 3：开启 GitHub Pages

  1. 进入仓库页面，点击 Settings
  2. 左侧菜单找到 Pages
  3. Source 选择 Deploy from a branch
  4. Branch 选择 main，文件夹选 / (root)
  5. 点击 Save

等待 1-2 分钟后，页面顶部会显示你的在线地址：

https://你的用户名.github.io/ai-book/

步骤 4：验证

访问上面的地址，应该能看到目录首页。点击任意文章卡片，检查：

  • 封面信息条是否正常显示
  • 图片是否加载（路径 images/第XX篇/）
  • 数学公式是否渲染（MathJax CDN）
  • 代码块是否高亮（highlight.js CDN）
关键文件说明
文件作用
.nojekyll告诉 GitHub Pages 不要用 Jekyll 处理，直接原样部署
_config.ymlPages 配置信息（标题、描述）
index.html目录首页，所有文章的入口

方案二：Markdown 离线文件

仓库根目录下的 .md 文件即为 Markdown 源文件，可直接下载离线阅读。

阅读方式

  • Typora：付费 Markdown 编辑器，渲染效果最好，支持导出 PDF / EPUB / DOCX
  • Obsidian：免费笔记工具，支持双向链接和图谱视图
  • VS Code：安装 Markdown Preview Enhanced 插件
  • 直接 GitHub 浏览：在 GitHub 仓库页面直接点击 .md 文件在线预览

导出为电子书（PDF / EPUB）

使用 Typora 导出最简单：

  1. 用 Typora 打开任意 .md 文件
  2. 菜单栏 File → Export → PDF / EPUB / HTML
  3. 图片路径 images/第XX篇/ 为相对路径，只要 images 目录在同级就会正常显示

批量导出可使用 Pandoc：

# 安装 Pandoc
brew install pandoc

# 单篇导出 PDF（需要 LaTeX）
pandoc "门外汉学 AI，不用怕！（1）...md" -o 第01篇.pdf --pdf-engine=xelatex -V CJKmainfont="PingFang SC"

# 合并为一本电子书
cat *.md > 全书.md
pandoc 全书.md -o 门外汉学AI.pdf --pdf-engine=xelatex -V CJKmainfont="PingFang SC"

代码高亮highlight.js 自动高亮取决于编辑器

离线可用否（需联网）是
导出 PDF浏览器打印Typora / Pandoc
适合场景在线分享、传播离线阅读、出书印刷

更新内容

后续修改文章后，只需重新推送到 GitHub：

git add .
git commit -m "更新第XX篇"
git push

GitHub Pages 会在 1-2 分钟内自动更新。
